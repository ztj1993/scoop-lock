# Navicat Premium 17 使用指南

## 简介

Navicat Premium 是一款功能强大的多数据库管理和开发工具，支持同时连接到多种不同类型的数据库。它提供了直观的图形界面，使数据库管理员和开发者能够高效地进行数据库管理、开发和维护工作。

- **版本**: Navicat Premium 17
- **许可证**: 商业软件（需购买许可证）
- **官方网站**: https://www.navicat.com.cn/products/navicat-premium

### 支持的数据库

Navicat Premium 17 支持以下数据库系统及云数据库：

| 数据库 | 说明 |
|--------|------|
| MySQL | 世界上最流行的开源关系数据库 |
| MariaDB | MySQL 的分支，完全兼容 |
| PostgreSQL | 功能强大的开源对象关系数据库 |
| MongoDB | 流行的 NoSQL 文档数据库 |
| Oracle | 企业级关系数据库管理系统 |
| SQL Server | 微软的关系数据库管理系统 |
| SQLite | 轻量级嵌入式关系数据库 |
| Redis | 高性能键值内存数据库 |
| Snowflake | 云原生数据仓库 |

## 主要功能

### 数据库连接管理

Navicat Premium 提供了统一的连接管理界面：

- 支持同时连接多种类型的数据库
- 连接分组与标签管理
- 支持 SSH 隧道和 HTTP 隧道连接
- SSL/TLS 安全连接
- 连接配置导入与导出
- 连接颜色标记与环境标识（开发、测试、生产）

### 数据查看与编辑

- **网格视图**: 以表格形式查看和编辑数据
- **表单视图**: 以表单形式查看单条记录
- **文本视图**: 查看大型文本/BLOB/JSON 数据
- **内联编辑**: 直接在网格中编辑数据
- **批量编辑**: 同时修改多条记录
- **数据筛选与排序**: 多条件组合筛选、多列排序
- **数据特征分析 (Data Profiling)**: Navicat 17 新增的数据概览与统计分析功能

### SQL 编辑器

强大的 SQL 编辑与分析功能：

- **语法高亮与智能提示**: 支持各数据库特有语法的自动补全
- **代码片段**: 预定义和自定义 SQL 代码片段
- **SQL 格式化**: 一键自动美化 SQL 语句
- **可视化解释 (Visual Explain)**: 直观分析查询执行计划与性能瓶颈
- **聚焦模式 (Focus Mode)**: 提供沉浸式编写体验
- **多标签编辑**: 支持拆分窗口与多标签协同

### 数据库设计与建模

可视化的数据库设计工具：

- **ER 图表**: 自动生成和编辑物理/逻辑实体关系图
- **表设计器**: 可视化创建和修改字段、索引、外键、约束
- **逆向工程**: 从现有数据库提取结构生成模型
- **正向工程**: 从模型生成多数据库 DDL 脚本
- **模型同步**: 比较模型与数据库之间的结构差异并同步

### 数据传输与同步

- **数据传输**: 跨类型数据库间高效传输数据
- **结构同步**: 深度对比两端结构并生成差异同步脚本
- **数据同步**: 对比表数据差异，支持批量更新与回滚脚本生成
- **数据字典**: 自动生成数据库文档报表

### 数据导入与导出

支持多种文件格式转换：

- **导入向导**: CSV、Excel、JSON、XML、SQL、Access 等
- **导出向导**: CSV、Excel、JSON、XML、HTML、PDF、SQL 等
- **定时任务**: 自动化定时执行备份、导入导出与查询运行

### 协作与云服务

- **Navicat Cloud**: 云端同步连接配置、查询脚本与模型
- **团队协同**: 团队共享连接与开发资源

## 常用命令/操作

### 安装

通过 Scoop 安装：

```powershell
scoop install navicat17
```

### 更新

更新至最新版本：

```powershell
scoop update navicat17
```

### 卸载

卸载命令：

```powershell
scoop uninstall navicat17
```

### 创建数据库连接

1. 点击工具栏的 "连接" 按钮或菜单 "文件" -> "新建连接"
2. 选择数据库类型（如 MySQL、PostgreSQL 等）
3. 填写连接信息：
   - **连接名**: 自定义名称
   - **主机**: 数据库服务器地址（如 `localhost` 或远程 IP）
   - **端口**: 数据库端口（如 MySQL 默认 3306）
   - **用户名**: 数据库用户名
   - **密码**: 数据库密码
   - **默认数据库**: 可选，指定默认打开的数据库
4. 点击 "测试连接" 验证连接可用性
5. 点击 "确定" 保存连接

### 执行 SQL 查询

1. 右键点击数据库，选择 "新建查询" 或按 `Ctrl+Q`
2. 在 SQL 编辑器中编写 SQL 语句
3. 使用 `Ctrl+Shift+R` 获取代码补全建议
4. 点击 "执行" 按钮或按 `Ctrl+R` 执行当前查询
5. 在下方结果面板查看数据或执行信息

### 导出与导入数据

1. 右键点击目标表或数据库，选择 "导出向导" 或 "导入向导"
2. 选择源格式与目标格式（如 Excel、CSV、JSON）
3. 配置字段映射与分隔符
4. 开始执行并查看处理进度

## 常见问题

### Q: 连接数据库时提示 "Access denied" 怎么办？

- 检查用户名和密码是否正确
- 确认数据库用户拥有当前来源 IP 的访问权限
- 确认目标数据库端口已被防火墙放行
- 对于 MySQL，可在服务器端执行：

```sql
GRANT ALL PRIVILEGES ON *.* TO 'username'@'%' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;
```

### Q: 中文数据显示乱码怎么办？

- 确认数据库与表的字符集设置（推荐 `utf8mb4`）
- 在 Navicat 连接属性 -> "高级" 标签页中将编码设置为 "65001 (UTF-8)"
- 确保导入导出文件编码一致

### Q: 大数据量查询时界面卡顿如何处理？

- 在 SQL 语句中使用 `LIMIT` 进行分页查询
- 在选项中限制每次检索记录数（默认一般为 1000 行）
- 为高频筛选与排序字段建立合理索引
